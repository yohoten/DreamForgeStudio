AI Agent Studio Orchestration

DreamForgeStudio

造梦游戏工坊

面向 HTML5 页游、微信小游戏 与 抖音小游戏 的 AI Agent 工作室编排平台。 把不同部门、不同角色的 AI Agent 接成一条可控流水线，再用一间等距办公室把它们的走动、 排队、交付和吵架都摆在眼前。

Agent 通过 OpenAI 兼容 HTTP API 连接本地推理端点（Ollama / vLLM / LM Studio） 或云端模型；本地跑不动时自动外包到云端，云端太贵时自动退回本地。

01

工作室里有什么

界面上的每个抽屉面板对应一套已接入后端的真实能力，不是占位。以下按你在左侧菜单栏能看到的结构排列。

招聘中心

市场 / 派单 / 体检三页。「初期模式」每类只留 1 人压低负载，也可一键全员在岗；体检会跑粗测与阶梯扫描，输出设备画像与可执行建议。

/api/hire · /api/bench · /api/advice

会议室

立项 / 章程 / 变更三段。走会议模型生成章程草稿、里程碑与验收点；模型不可用时有规则兜底，偏离已归档章程会自动提醒。

/api/meeting/* · /api/charter/*

沙盘看板

绩效排行 / 任务流水线 / 工作流 / 编排 / Sprint 五个视图。资源仪表盘同时盯预算、能量与士气三条线。

scoreboard · pipeline · workflow · orchestrator · sprint

拖拽编排器

Agent 节点与工具节点（起点 / 条件分支 / 审批 / 终点）拖到画布上连线，保存即成为可执行流程。

SVG canvas · 节点属性面板

三总监策略

制作人管拆单派单，技术总监管降级外包，创意总监管验收门禁。默认规则模式可玩可控，每人均可单独切到模型增强。

/api/policy

任务队列

优先级排序与并发槽位控制，HTML 产物自动校验失败重试。连锁派单按「策划→程序→美术→QA」自动入队。

/api/queue · /api/queue/enqueue

财务与计费

按 token 估算今日请求数、失败数、成本与提供方分布，含失败原因归类。成本口径目前为估算，待接上游 usage 后收窄。

/api/finance/summary · /api/finance/reset

资产管线

生图、打包 spritesheet、视频转码三条独立通路，产物写入显示器预览区；把 AI 写出的 HTML 粘进预览框即可留档并回看历史版本。

asset-pipeline.ts · /api/preview/*
02

四阶段流水线

任务从立项落到四处工位，任一环节积压会被判定为瓶颈并高亮；delay 与排队情况在流水中实时写出。

STAGE 01
策划 / 设计
需求拆解、立项章程、里程碑与验收点
STAGE 02
程序 / 工程
HTML 首包产出，超时则降级或外包
STAGE 03
美术 / 音频
贴图、spritesheet 打包与转码，常见积压点
STAGE 04
QA / 发布
自动验证、多端适配检查与放行

Sprint 以 7 天为一周期推进：资源分配 → 执行 → 验收 → 复盘。可以手动「推进 1 天」， 用来观察士气、预算与积压如何随时间变化。

03

模型路由

三档路由决定「执行」和「会议」分别花谁的钱。三个总监派单时走会议侧， 招聘卡片上的个体绑定可以覆盖全局档位。

省钱
  • 执行：本地
  • 会议：本地
  • 零 API 成本，速度取决于本机
均衡 · 默认
  • 执行：本地
  • 会议：云端
  • 干活用本机，决策用云端
高质量
  • 执行：云端
  • 会议：云端
  • 全链路云端，成本最高

支持 DeepSeek、Moonshot、MiniMax 预设与本地 Ollama；也能直接填任意 OpenAI 兼容的 BaseURL。

04

跑起来

需要 Node.js 18 及以上。根 workspace 会同时拉起前后端两个进程。

bash — DreamForgeStudio 
# 安装依赖（npm workspaces 会一并处理 apps/* 与 packages/*）
npm install

# 同时启动 server(8787) 与 web(5173)
npm run dev

# 只起一端时用
npm run dev:server
npm run dev:web

# 端到端冒烟：真实改名 + 队列 + 回退链路自检
npm run check:studio-e2e

首次打开建议先进连接设置填 BaseURL 与模型名，点「测试」确认通；本地报显存不足时换成更小模型或让 Ollama 走 CPU。
